# 🎵 Spotify 2

Uma página web temática e interativa dedicada à apreciação da música, explorando sua definição, importância cultural e os benefícios para a mente, com navegação voltada para diferentes gêneros musicais.

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na estruturação de páginas web, utilizando elementos visuais clássicos e conteúdos informativos sobre o impacto da música no desenvolvimento mental, bem-estar e concentração.

## ✨ Destaques & Funcionalidades
- **Apresentação Animada:** Título dinâmico e chamativo em destaque.
- **Conteúdo Informativo:** Textos sobre a definição de música e seus benefícios cognitivos.
- **Navegação por Gêneros:** Links de acesso rápido para páginas dedicadas a diferentes estilos musicais:
  - Pop
  - Rock
  - R&B
  - Bossa Nova

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação e tags estruturais/visuais)
